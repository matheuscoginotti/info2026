O Caminho para o Sistema de Login

O nosso grande objetivo para o Projeto Final é construir um site completo com um Sistema de Login. Mas como é que o computador sabe se a senha está certa ou errada?

Na Aula 5 nós aprendemos a desenhar o formulário (o <input>). Na Aula 14 aprendemos a ouvir o clique do botão. Hoje, vamos aprender as peças que faltavam: como pegar o que o utilizador digitou e fazer o computador tomar uma decisão com base nisso.

Analogia do Segurança da Porta 🚪🤵

Imagine um segurança na porta de uma festa VIP (O nosso JavaScript).

1. Captura: Primeiro, ele pede o seu Bilhete de Identidade (Ele lê o que você digitou no Input).
2. Lógica (SE/SENÃO): Ele pensa: "SE (IF) o nome estiver na lista, eu abro a porta. SENÃO (ELSE), eu bloqueio a entrada".

O JS faz exatamente isto: avalia uma condição e decide qual caminho seguir!

1. O Dicionário do Segurança (Sintaxe)

Antes de criarmos o nosso sistema, vamos revisar e entender cada palavra que o nosso "Segurança" (JavaScript) vai usar no código de hoje:

const e let (Memória)

Lembram-se da aula passada? O JS precisa de caixas para não se esquecer das coisas. Usamos const (constante) para guardar os botões do HTML que não vão mudar. E usamos let (variável) para guardar a senha, pois o utilizador pode digitar algo diferente de cada vez.

querySelector (A Luneta)

O JS usa este comando para procurar e "pescar" um elemento lá do HTML (como #campo-senha) para poder controlá-lo.

.value (Ler o que foi digitado)

Quando "pescamos" um <input>, usamos o .value para extrair exatamente o texto que o utilizador acabou de digitar dentro da caixinha.

let senhaDigitada = input.value;

=== (Comparação Absoluta)

Na matemática usamos '=' para igual. No JS, '=' significa guardar um valor. Para perguntar se é igual, usamos três sinais ===.

if (senhaDigitada === "123") { ... }

.textContent (Escrever na Tela)

Permite ao JS alterar dinamicamente o texto que está dentro de uma tag HTML (como um parágrafo).

paragrafo.textContent = "Olá Mundo!";

.style (Mudar o CSS)

Permite ao JS mudar as cores e o visual (como se fosse o CSS). Se a senha estiver errada, podemos mudar a cor para vermelho!

paragrafo.style.color = "red";

2. A Estrutura If / Else

Esta é a estrutura mais poderosa da programação. Ela divide o caminho do seu código em dois cenários possíveis. If significa "Se" e Else significa "Senão".

Sintaxe Padrão da Lógica de Decisão:

if (condição_for_verdadeira) {
    // Executa este bloco e ignora o de baixo
} else {
    // Se for falsa, executa este bloco e ignora o de cima
}

3. Prática: O Mini Sistema de Login

Vamos construir o "avô" do nosso futuro sistema de login usando tudo o que vimos acima. Um campo de senha, um botão e uma mensagem que reage se você acertou ou errou a senha secreta.

<!-- =========================================================
    ARQUIVO 1: index.html (O Formulário)
========================================================= -->
<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="caixa-login">
        <h2>Acesso Restrito</h2>
        
        <label>Digite a Senha Secreta:</label>
        <!-- O input onde o utilizador digita -->
        <input type="password" id="campo-senha" placeholder="******">
        
        <button id="btn-entrar">Verificar Acesso</button>
        
        <!-- Um parágrafo vazio que o JS vai preencher com a resposta -->
        <p id="mensagem-feedback"></p>
    </div>

    <script src="script.js"></script>
</body>
</html>


// =========================================================
//  ARQUIVO 2: script.js (A Lógica do Segurança)
// =========================================================

// 1. PESCAR OS ELEMENTOS COM CONSTANTES E QUERYSELECTOR
const inputSenha = document.querySelector('#campo-senha');
const botaoEntrar = document.querySelector('#btn-entrar');
const textoMensagem = document.querySelector('#mensagem-feedback');

// 2. OUVIR O CLIQUE DO BOTÃO
botaoEntrar.addEventListener('click', function() {
    
    // Quando clica, o JS extrai o .value do input
    // Usamos 'let' porque essa tentativa muda a cada clique
    let tentativa = inputSenha.value;
    
    // 3. A LÓGICA DE DECISÃO (O Segurança usando ===)
    // Vamos imaginar que a senha correta seja "etec2026"
    if (tentativa === "etec2026") {
        
        // SE FOR VERDADE (A senha bateu perfeitamente)
        // Usamos textContent para escrever na tela e style.color para pintar
        textoMensagem.textContent = "Acesso Permitido! Bem-vindo.";
        textoMensagem.style.color = "green";
        
    } else {
        
        // SENÃO (A senha está errada)
        textoMensagem.textContent = "Acesso Negado! Senha incorreta.";
        textoMensagem.style.color = "red";
        
    }
});

4. Atividade: O Guardião do Sistema

Vamos testar a sua lógica! Modifique o código base acima:

1

Mudando o Segredo: Altere a lógica no JS para que a senha secreta seja o seu primeiro nome em letras minúsculas. Teste no navegador acertando e errando.

2

UX (Experiência do Utilizador): No bloco do else, adicione a linha: inputSenha.value = ""; para que o campo de senha se limpe automaticamente quando a pessoa errar a senha.

3

CSS do Formulário: Crie um ficheiro style.css (Aula 13) e centralize a .caixa-login na tela usando larguras, margens automáticas, sombras e bordas arredondadas.

4

Desafio Extra (Avançado): Adicione mais um <input type="text" id="campo-usuario"> no HTML. No JS, pesque esse ID com o `querySelector` e guarde o seu `.value`. O segurança agora só deixa entrar se o utilizador for "admin" E a senha for correta.
