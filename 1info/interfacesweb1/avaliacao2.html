Atividade Avaliativa (Aulas 15 a 20)

Dashboard Tech-Freela

Desenvolvimento de Interface, Responsividade e Interação

Objetivo e Instruções

Você foi contratado(a) como Desenvolvedor Front-End freelancer para construir o Painel de Controle de uma startup. O designer enviou a estrutura HTML base. A sua missão é criar os arquivos style.css e script.js aplicando todo o conhecimento das Aulas 15 a 20 para estilizar o layout com Flexbox, torná-lo responsivo para telemóveis e adicionar a função do Modo Escuro com JavaScript.

Regras de Ouro:

  • Você não pode alterar as classes ou os IDs do arquivo HTML fornecido abaixo.
  • A consulta aos materiais das Aulas 15 a 20 é totalmente permitida.

Requisitos Técnicos (10 Tarefas)

1 Fase 1: O Esqueleto e Flexbox Base

T1. O Reset Base

Selecione o body, zere a margem externa (margin: 0) e defina a fonte da página (font-family: sans-serif).

T2. Estrutura Principal

A classe .container-principal deve usar display: flex. O Menu Lateral terá largura de 250px, e o Conteúdo deve preencher o resto (flex: 1).

T3. Menu Empilhado

Use Flexbox no .menu-lateral com direção em coluna (flex-direction: column). Adicione espaçamento (gap).

T4. Cabeçalho Extremos

No .cabecalho-flex, separe o título e o botão nos extremos usando justify-content: space-between e alinhe-os ao centro verticalmente.

T5. Cartões com Flex Wrap

A .area-cartoes precisa de display: flex e flex-wrap: wrap para os cartões descerem de linha se a tela encolher. Aplique um gap: 20px.

2 Fase 2: Interatividade e Responsividade

T6. Interação Hover:

Ao passar o mouse ( :hover ) sobre um .cartao, faça-o subir levemente (transform: translateY(-5px)) e aumente a sombra.

T7 e T8. Breakpoint e Inversão Mobile:

Crie um radar @media (max-width: 768px). Dentro dele, altere a direção da .container-principal para column, forçando o menu a ficar no topo. Em seguida, mude a largura do menu para 100%.

T9. Escondendo Elementos (Mobile):

Ainda dentro do Media Query, selecione a classe .aviso-desktop e use display: none para que a frase não apareça no telemóvel.

T10. Motor JavaScript (Modo Escuro):

No arquivo script.js, selecione o #btn-escuro. Adicione um ouvinte de evento (click) que injete uma classe no body (ou modifique diretamente o style) para escurecer o fundo do .conteudo.
