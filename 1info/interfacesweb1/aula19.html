Módulo 5: Layouts Modernos

Aula 19: O Design Fluido

Como criar sites responsivos sem adivinhar o tamanho da tela

A Morte das Medidas Fixas

No passado, os programadores tentavam adivinhar o tamanho da tela do utilizador para escrever regras de CSS específicas. "Se tiver 320px, faz isto. Se tiver 768px, faz aquilo". Hoje, com milhares de telemóveis diferentes, isso é impossível.

A Analogia da Água e o Copo Inteligente 💧

Em vez de adivinharmos o tamanho do copo, nós damos inteligência à água.

O CSS moderno possui funções matemáticas automáticas. Nós dizemos ao navegador: "Crie quantas colunas couberem aqui. O tamanho ideal é 250px, mas se não couber, jogue a coluna para a linha de baixo automaticamente". Isso chama-se Design Fluido, e é o segredo dos sites profissionais. Usamos os antigos `@media queries` apenas como último recurso.

1. O Dicionário da Fluidez

Conheça as ferramentas modernas que substituem dezenas de linhas de código antigo:

A Tag viewport

Obrigatória no HTML. Sem ela, o telemóvel tentará "dar zoom out" no site inteiro para caber na tela, ignorando o seu CSS fluido.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

flex-wrap: wrap;

A salvação do Flexbox. Diz aos elementos filhos: "Se a tela ficar apertada, não se esmaguem! Podem pular para a linha de baixo."

clamp(min, ideal, max)

A melhor forma de criar fontes responsivas. Ex: O tamanho da letra será no mínimo 16px, idealmente 3% da tela, mas nunca passará de 32px.

font-size: clamp(16px, 3vw, 32px);

auto-fit e minmax() (CSS Grid)

O truque mais poderoso do Grid. Cria colunas automaticamente! "Crie quantas colunas couberem, desde que tenham no mínimo 250px e no máximo 1 fração (1fr) do espaço."

grid-template-columns:
repeat(auto-fit, minmax(250px, 1fr));

2. Prática: O Dashboard Automático

Repare como construímos uma área de relatórios incrivelmente avançada que se adapta a qualquer ecrã, sem usar um único "@media" para adivinhar a resolução!

<!-- =========================================================
    ARQUIVO 1: index.html
========================================================= -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <!-- Sem esta tag, o telemóvel ignora a responsividade! -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <header class="cabecalho">
        <!-- Esta fonte vai crescer e encolher sozinha com o clamp! -->
        <h1 class="titulo-fluido">Relatórios do Sistema</h1>
    </header>

    <!-- AQUI ESTÁ A MAGIA! -->
    <main class="grade-automatica">
        <!-- Tente adicionar ou remover cartões no HTML. 
             Eles vão arrumar-se sozinhos no ecrã! -->
        <div class="cartao">Vendas do Mês: 5.000€</div>
        <div class="cartao">Novos Clientes: 120</div>
        <div class="cartao">Tickets Abertos: 15</div>
        <div class="cartao">Metas Atingidas: 80%</div>
    </main>

</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css (Magia CSS Moderna)
========================================================= */
body { 
    margin: 0; 
    font-family: sans-serif; 
    background-color: #f8fafc;
}

.cabecalho {
    background-color: #1e293b;
    color: white;
    padding: 20px;
    text-align: center;
}

/* TEXTO FLUIDO COM CLAMP() */
.titulo-fluido {
    margin: 0;
    /* Lê-se: Fica com 20px no telemóvel, tenta usar 4% da largura da tela, 
       mas se a tela for um cinema, não passe de 40px */
    font-size: clamp(20px, 4vw, 40px);
}

/* ----------------------------------------------------
   GRID FLUIDO: O TRUQUE DE NÍVEL SÊNIOR
---------------------------------------------------- */
.grade-automatica {
    display: grid;
    gap: 20px;
    padding: 30px;
    
    /* Adeus @media queries! 
       'auto-fit': Preencha a linha com o máximo de colunas que der.
       'minmax': Cada coluna deve ter NO MÍNIMO 250px. 
                 Se sobrar espaço na tela, divida por igual (1fr).
       Se a tela encolher para menos de 250px, jogue a coluna para baixo! */
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

.cartao {
    background-color: white;
    padding: 30px;
    border-radius: 10px;
    box-shadow: 0 4px 6px rgba(0,0,0,0.05);
    text-align: center;
    font-weight: bold;
    color: #334155;
}

3. Atividade: O Inspetor de Telas

Para testar o verdadeiro poder do CSS moderno, abra o seu site e redimensione a janela do navegador arrastando a borda, ou pressione F12 e clique no ícone de telemóvel!

1

Mágica do Grid: Abra o site no computador (você verá 4 cartões lado a lado). Comece a encolher a tela lentamente. Note o momento exato em que os cartões não cabem mais e começam a pular para a linha de baixo, formando 2 colunas, e depois 1 coluna no formato telemóvel!

2

Ajustando o MinMax: No CSS da .grade-automatica, altere o valor de 250px para 400px. Como isso afeta o momento em que os cartões "quebram" para a linha de baixo?

3

Brincando com o Clamp: Na classe .titulo-fluido, mude o valor mínimo do `clamp` de 20px para 10px. Abra o site como telemóvel e veja como a fonte agora ficou minúscula!

4

O @media como Último Recurso: Digamos que no telemóvel queremos esconder completamente o cabeçalho. Adicione este código no final do CSS e veja a magia:
@media (max-width: 600px) { .cabecalho { display: none; } }

Aula 19 concluída. O seu site agora possui design fluido e automático!
