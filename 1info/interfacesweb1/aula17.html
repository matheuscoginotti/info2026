Aula 17: O Design Interior

Flexbox II e a Arte de Estilizar Formulários

Organizando as Gavetas

Na Aula 16, usamos o Flexbox no <body> para colocar a nossa Caixa de Login bem no meio da tela. Mas e dentro da caixa?

A Analogia da Estante Vertical 📚

Um formulário de login padrão tem os elementos empilhados de cima para baixo: o título, o campo de e-mail, o campo de senha e o botão.

O Flexbox também pode ser usado dentro da caixa de login para agir como uma estante. Em vez de usar várias tags <br> para dar espaços feios ou margens confusas, nós transformamos a caixa de login num container Flex com direção de coluna.

1. O Dicionário Flex II e Formulários

Novas propriedades para dominar o espaço interno e o visual profissional dos inputs:

flex-direction: column;

Transforma o trilho horizontal (padrão do flex) num elevador. Todos os inputs e botões ficam empilhados verticalmente.

gap: 15px; (A Mágica do Espaço)

Esqueça a dor de cabeça de colocar margens em cada elemento. O gap cria um espaço perfeito, automático e idêntico entre todos os itens do seu Flexbox!

gap: 20px;

outline: none;

Sabe aquela borda preta ou azul feia que aparece quando você clica num input no navegador? O outline remove isso para você criar a sua própria borda bonita.

A Pseudo-classe :focus

Funciona como o :hover (passar o mouse), mas o :focus é ativado quando o utilizador clica dentro do input para começar a digitar.

input:focus { border-color: blue; }

2. Prática: O Formulário Profissional

Veja como o CSS transforma um form feio numa tela de login digna de empresas gigantes usando Flexbox em Coluna e estilos de Input.

<!-- =========================================================
    ARQUIVO 1: index.html
========================================================= -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <!-- Nossa caixa de login da Aula 16 -->
    <div class="caixa-login">
        <h2>Acesse sua Conta</h2>
        
        <!-- Usamos a tag <form> para envolver os inputs -->
        <form class="form-flex">
            <input type="email" class="meu-input" placeholder="exemplo@etec.sp.gov.br">
            <input type="password" class="meu-input" placeholder="Sua senha">
            <button type="button" class="meu-botao">Entrar no Sistema</button>
        </form>
    </div>

</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css
========================================================= */
/* Reset básico e alinhamento do Body (Aula 16) */
body {
    margin: 0;
    background-color: #f1f5f9;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    font-family: sans-serif;
}

.caixa-login {
    background-color: white;
    padding: 40px;
    border-radius: 12px;
    box-shadow: 0 10px 25px rgba(0,0,0,0.1);
    width: 360px;
    text-align: center;
}

/* ----------------------------------------------------
   A MAGIA DO FLEXBOX INTERNO NO FORMULÁRIO 
---------------------------------------------------- */
.form-flex {
    display: flex;
    flex-direction: column; /* Empilha de cima para baixo */
    gap: 20px; /* Cria 20px de espaço entre cada input/botão automaticamente! */
    margin-top: 25px;
}

/* ----------------------------------------------------
   ESTILIZANDO OS INPUTS COMO PROFISSIONAL
---------------------------------------------------- */
.meu-input {
    padding: 14px;
    border: 2px solid #e2e8f0; /* Borda cinza claro */
    border-radius: 8px;
    font-size: 16px;
    outline: none; /* Remove a borda azul nativa do navegador */
    transition: 0.3s;
}

/* Quando o utilizador clica dentro do input */
.meu-input:focus {
    border-color: #0ea5e9; /* A borda fica azul cyan ao digitar */
}

/* ----------------------------------------------------
   ESTILIZANDO O BOTÃO
---------------------------------------------------- */
.meu-botao {
    background-color: #0ea5e9; /* Azul Cyan */
    color: white;
    padding: 14px;
    border: none;
    border-radius: 8px;
    font-weight: bold;
    cursor: pointer;
    transition: 0.3s;
}

.meu-botao:hover {
    background-color: #0284c7; /* Fica mais escuro ao passar o mouse */
}

3. Atividade: Lapidando o Layout

Aplique estas modificações no código para entender a magia do Flexbox em colunas:

1

O Poder do Gap: No CSS .form-flex, mude o gap para 40px. Veja como tudo se distancia de forma perfeita sem usar uma única tag <br>.

2

Invertendo Eixos: No .form-flex, apague a linha flex-direction: column; (ele voltará para row). O que aconteceu com os inputs e o botão?

3

Cores de Foco: Altere a cor do border-color no .meu-input:focus para #22c55e (Verde). Clique dentro do input para testar o efeito.

4

Botão Secundário: Adicione um link <a href="#" class="link-senha">Esqueci minha senha</a> logo abaixo do botão no HTML. Graças ao Flexbox e ao `gap`, ele vai alinhar-se perfeitamente embaixo do botão!
