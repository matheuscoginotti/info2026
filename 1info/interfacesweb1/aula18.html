Módulo 5: Layouts Modernos

Aula 18: O Arquiteto Grid

Construindo o Painel Principal (Dashboard) Pós-Login

Para Além do Flexbox

O Flexbox é incrível para alinhar coisas num único sentido (linha ou coluna), como o nosso formulário de login. Mas e quando o utilizador entrar no sistema?

A Analogia da Planta Baixa 🗺️

Um painel de sistema (Dashboard) precisa de um menu lateral, um cabeçalho no topo, uma área de gráficos e um rodapé.

O CSS Grid é como o arquiteto que desenha a planta baixa da casa inteira de uma só vez. Diferente do Flexbox (que é 1D), o Grid trabalha em 2D: ele controla linhas e colunas simultaneamente, permitindo que você diga exatamente em que "quadrado" cada parte do site deve ficar.

1. O Dicionário Grid (Sintaxe)

Assim como o Flexbox, a magia do Grid acontece no elemento PAI (o container):

display: grid;

Avisa ao navegador que este elemento será regido pelas regras do Grid, preparando o terreno em branco.

grid-template-columns

Define quantas colunas o layout terá e as suas larguras. Exemplo: 200px 1fr 1fr; cria 3 colunas (uma fixa de 200px e duas que dividem o espaço restante).

grid-template-columns: 250px 1fr;

grid-template-rows

Define as alturas das linhas. Exemplo: 80px 1fr 50px; cria um topo fixo, um meio flexível e um rodapé fixo.

grid-template-rows: auto 1fr;

A Unidade fr (Fração)

É a unidade mágica do Grid. 1fr significa "1 fração do espaço disponível". Resolve problemas de cálculos percentuais.

2. Prática: Estruturando o Dashboard

Este é o esqueleto clássico do painel que o utilizador verá após o login: um Menu Lateral, um Cabeçalho Superior e uma Área Central de Conteúdo.

<!-- =========================================================
    ARQUIVO 1: index.html
========================================================= -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- O CONTAINER PAI (Onde vai a regra do GRID) -->
    <div class="grid-container">
        
        <!-- FILHO 1: O Menu Lateral (Sidebar) -->
        <nav class="menu-lateral">
            <h2>Sistema Etec</h2>
            <ul>
                <li>Dashboard</li>
                <li>Relatórios</li>
                <li>Configurações</li>
            </ul>
        </nav>

        <!-- FILHO 2: O Cabeçalho (Header) -->
        <header class="cabecalho">
            Bem-vindo, Matheus! <button>Sair</button>
        </header>

        <!-- FILHO 3: A Área Principal (Main Content) -->
        <main class="conteudo-principal">
            <h1>Resumo de Vendas</h1>
            <p>Aqui entra o gráfico ou a tabela de dados...</p>
        </main>

    </div>

</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css
========================================================= */
body {
    margin: 0;
    font-family: sans-serif;
}

/* A PLANTA BAIXA DO ARQUITETO (GRID) */
.grid-container {
    display: grid;
    
    /* Definindo as Colunas: 
       A primeira terá exatamente 250px (para o menu lateral).
       A segunda usará todo o espaço restante (1fr). */
    grid-template-columns: 250px 1fr;

    /* Definindo as Linhas:
       A primeira terá 70px de altura (para o cabeçalho).
       A segunda usará todo o espaço restante (1fr). */
    grid-template-rows: 70px 1fr;
    
    /* Altura total da tela para o Grid não encolher */
    height: 100vh;
}

/* ----------------------------------------------------
   ESTILIZANDO E POSICIONANDO OS FILHOS
---------------------------------------------------- */

/* Menu Lateral: Vai ocupar a coluna 1 e atravessar as linhas 1 e 2 */
.menu-lateral {
    background-color: #1e293b; /* Azul Escuro */
    color: white;
    padding: 20px;
    
    /* COMANDO MÁGICO: Estica a barra lateral desde o topo até o fim */
    grid-row: 1 / 3; 
    grid-column: 1 / 2;
}

/* Cabeçalho: Fica na coluna 2, linha 1 */
.cabecalho {
    background-color: #ffffff;
    padding: 0 30px;
    display: flex; /* Olha o Flexbox ajudando dentro do Grid! */
    justify-content: space-between;
    align-items: center;
    box-shadow: 0 2px 5px rgba(0,0,0,0.1); /* Sombra suave */
    
    grid-row: 1 / 2;
    grid-column: 2 / 3;
}

/* Área Central: Fica na coluna 2, linha 2 */
.conteudo-principal {
    background-color: #f1f5f9;
    padding: 30px;
    
    grid-row: 2 / 3;
    grid-column: 2 / 3;
}

3. Atividade: O Construtor Digital

Altere as medidas da sua "planta baixa" para testar o comportamento do CSS Grid:

1

Aumentando o Menu: No .grid-container, altere o valor de 250px do grid-template-columns para 400px. Veja como o menu lateral cresce e o conteúdo principal encolhe automaticamente.

2

Apertando o Cabeçalho: Reduza o valor 70px do grid-template-rows para 40px. Observe como toda a linha do topo diminui uniformemente.

3

Quebrando a Regra Mágica: No CSS da .menu-lateral, altere a linha grid-row: 1 / 3; para grid-row: 2 / 3;. O que acontece com o topo do menu lateral? Ele ainda encosta no teto da tela?

4

Desafio Extra (Gap): Adicione a propriedade gap: 10px; no seu .grid-container. Note que as "linhas da planta" se separam umas das outras revelando o fundo da página.
