Aula 20: O Design Mutante

Responsividade, Breakpoints e a Filosofia Mobile-First

Um Site, Múltiplas Telas

Pense no nosso Projeto Final (O Sistema de Login e Dashboard). Ele precisa de funcionar no monitor gigante do laboratório da escola, mas também no Smartphone do utilizador, ou na tela de um tablet de 10 polegadas.

A Analogia da Água 💧

Como dizia Bruce Lee: "Se colocar água num copo, ela torna-se no copo. Se colocar numa garrafa, torna-se na garrafa."

O nosso site deve ser como a água. Chamamos a isso Design Responsivo. Em vez de criar um site para computador e outro site diferente para SmartPhone (como se fazia nos anos 2000), nós criamos um único código CSS com "radares" que detetam o tamanho da tela e mudam o layout em tempo real!

Mobile-First vs Desktop-First

Existem duas formas de escrever a responsividade. A mentalidade moderna dita que devemos desenhar para a tela mais difícil primeiro: o SmartPhone.

  • Desktop-First (max-width): Você constrói o site para o PC. Depois, diz ao CSS: "Se a tela tiver no máximo 768px, aplique estas restrições". O código tende a ficar cheio de "remendos".
  • Mobile-First (min-width): Você constrói o CSS padrão pensando numa tela pequena e numa só coluna. Depois, você diz: "Se a tela crescer e tiver no mínimo 1024px, coloque as colunas lado a lado". É mais rápido, mais leve e é o padrão da indústria.

1. Dicionário dos Breakpoints (Pontos de Quebra)

Para capturar as telas, nós estipulamos "Breakpoints". São as larguras exatas onde o layout se "quebra" e precisa de se reorganizar.

A Tag viewport

Fundamental! Sem ela, o SmartPhone tentará "espremer" o site de desktop para caber na tela, ignorando os nossos Media Queries.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

@media (O Radar CSS)

É um bloco condicional no CSS. Funciona como o 'If/Else' do JavaScript. O código aqui dentro SÓ EXISTE se a condição da tela for verdadeira.

@media (max-width: 768px) {
  /* Novo CSS aqui */
}

A Matemática dos Espaços

Responsividade não é só empilhar colunas. Num SmartPhone, padding: 50px é um desperdício enorme de tela! Devemos sempre reduzir os espaçamentos internos.

.caixa { padding: 15px; } /* no mobile */

Breakpoints Clássicos do Mercado

Estes são os valores mais utilizados pelas empresas na hora de criar radares responsivos:

  • 480px: SmartPhones pequenos.
  • 768px: Tablets (ex: iPad) em pé.
  • 1024px: Tablets deitados / Laptops.

2. Prática: O Dashboard Mutante

Vamos pegar no painel Grid da Aula 18 e fazê-lo "dobrar-se" para caber perfeitamente no SmartPhone usando a estratégia Desktop-First (para entenderem como desconstruir o layout).

<!-- =========================================================
    ARQUIVO 1: index.html
========================================================= -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <!-- Sem esta tag, o SmartPhone ignora a responsividade! -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <div class="grid-container">
        <nav class="menu-lateral">Menu do Sistema</nav>
        
        <header class="cabecalho">
            <h1>Bem-vindo ao Painel</h1>
        </header>
        
        <main class="conteudo-principal">
            <div class="aviso-pc">Este aviso só importa no PC.</div>
            <p>Os meus gráficos e dados super importantes...</p>
        </main>
    </div>

</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css (Abordagem Desktop-First)
========================================================= */
body { margin: 0; font-family: sans-serif; }

/* 1. LAYOUT BASE (Desenhado para Telas Grandes) */
.grid-container {
    display: grid;
    grid-template-columns: 250px 1fr; /* Menu à esquerda */
    grid-template-rows: 80px 1fr;
    height: 100vh;
}

.menu-lateral {
    background-color: #1e293b;
    color: white;
    padding: 20px;
    grid-row: 1 / 3;  /* Atravessa o topo até ao fundo */
    grid-column: 1 / 2;
}

.cabecalho {
    background-color: white;
    padding: 20px 40px; /* Muito espaço lateral para PC */
    box-shadow: 0 2px 5px rgba(0,0,0,0.1);
}

.cabecalho h1 { font-size: 32px; margin: 0; }

.conteudo-principal {
    background-color: #f1f5f9;
    padding: 40px; /* Área grande para respiro */
}

.aviso-pc {
    background-color: #fde047;
    padding: 10px;
    margin-bottom: 20px;
}

/* ----------------------------------------------------
   2. O RADAR MÁGICO (Media Query para SmartPhones)
---------------------------------------------------- */
/* Se a tela encolher para 768px (Tablet) ou menos... */
@media (max-width: 768px) {
    
    /* A. Mudança Estrutural Profunda */
    .grid-container {
        grid-template-columns: 1fr; /* Vira 1 coluna só! */
        grid-template-rows: auto auto 1fr; /* 3 Linhas */
    }

    .menu-lateral {
        grid-row: 1 / 2; /* Ocupa só a primeira linha agora */
        grid-column: 1 / 2;
        text-align: center;
    }
}

3. Laboratório UI: Adaptação Extrema

Responsividade não é só empilhar caixas, é otimizar o espaço. Resolva os desafios rigorosos abaixo modificando o CSS:

1

O Sumiço Espacial (Ocultar): O elemento .aviso-pc ocupa muito espaço na pequena tela do SmartPhone e não é vital. Escreva uma regra dentro do bloco @media para ocultá-lo completamente usando a propriedade de display correta.

2

O Espremedor (Espaçamento e Tipografia): O cabeçalho e o conteúdo têm muito espaço "inútil" no mobile (40px de padding e h1 com 32px). Adicione ao @media regras para reduzir o padding do .cabecalho e do .conteudo-principal para 15px, e o font-size do .cabecalho h1 para 22px.

3

Dança das Cadeiras (Grid Row): O Menu Lateral saltou para o topo do SmartPhone. No entanto, é melhor a nível de navegação que ele fique na parte inferior da tela (perto do polegar). Altere a propriedade grid-row do .menu-lateral dentro do @media para que ele vá para a última linha do container, e suba o cabeçalho e conteúdo.

4

O Intermediário (Breakpoint Tablet): Crie um NOVO bloco @media acima do atual. Ajuste o radar para agir apenas em tablets horizontais/pequenos monitores: @media (max-width: 1024px). Neste radar, não quebre em 1 coluna, mas diminua a largura do menu de 250px para apenas 80px (mudando o grid-template-columns do grid-container).

5

DESAFIO BOSS (Inversão Mobile-First):

Até agora criámos o site grande e cortámo-lo com o max-width. Isso está obsoleto! Inverta a lógica.

  • Remova todos os @media.
  • Escreva o CSS padrão (fora dos @media) para que ele seja a visualização em 1 só coluna (SmartPhone).
  • Crie um novo @media (min-width: 768px) e coloque dentro dele apenas o código necessário para esticar a tela de volta a 2 colunas para o Desktop!

Aula 20 concluída. Você domina os pontos de quebra e as medidas relativas!
