Aula 20: O Design Mutante

Responsividade, Media Queries e Mobile-First

Um Site, Múltiplos Ecrãs

Pense no nosso Projeto Final (O Sistema de Login e Dashboard). Ele precisa de funcionar no monitor gigante do laboratório da escola, mas também no telemóvel do utilizador no meio do autocarro.

A Analogia da Água 💧

Como dizia Bruce Lee: "Se colocar água num copo, ela torna-se no copo. Se colocar numa garrafa, torna-se na garrafa."

O nosso site deve ser como a água. Chamamos a isso Design Responsivo. Em vez de criar um site para computador e outro site diferente para telemóvel, nós criamos um único código CSS que deteta o tamanho da tela e muda a sua forma automaticamente!

1. O Dicionário da Responsividade

Como o nosso CSS deteta o tamanho da tela? Usando os "Radares de Tela" chamados Media Queries.

A Tag viewport

Lembra-se da Aula 1? Essa tag invisível no HTML é obrigatória. Sem ela, o telemóvel tenta encolher o site inteiro em vez de usar as regras responsivas.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

@media (O Radar)

É um bloco condicional dentro do CSS. Funciona como o 'If/Else' do JavaScript, mas para estilos visuais.

@media (regra-de-tamanho) {
  /* Novo CSS aqui */
}

max-width: 768px

Lê-se: "Se a tela tiver no máximo 768px (tamanho de um tablet ou menor), aplique este estilo". É usado para adaptar um site de PC para Telemóvel.

min-width: 768px (Mobile-First)

Lê-se: "Se a tela tiver no mínimo 768px, aplique este estilo". No mundo profissional, criamos o site primeiro para telemóvel e usamos isto para adaptá-lo para PC depois!

2. Prática: O Dashboard Mutante

Vamos pegar o nosso painel Grid da Aula 18 e fazê-lo "dobrar-se" para caber perfeitamente no telemóvel.

<!-- =========================================================
    ARQUIVO 1: index.html
========================================================= -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <!-- Sem esta tag, o telemóvel ignora a responsividade! -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- A mesma estrutura da Aula 18 -->
    <div class="grid-container">
        <nav class="menu-lateral">Menu Sistema</nav>
        <header class="cabecalho">Bem-vindo!</header>
        <main class="conteudo-principal">Os meus gráficos e dados...</main>
    </div>

</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css (Abordagem PC -> Telemóvel)
========================================================= */
body { margin: 0; font-family: sans-serif; }

/* 1. LAYOUT PADRÃO (Para Ecrãs Grandes / PC) */
.grid-container {
    display: grid;
    grid-template-columns: 250px 1fr; /* Menu à esquerda, resto do site à direita */
    grid-template-rows: 70px 1fr;
    height: 100vh;
}

.menu-lateral {
    background-color: #1e293b;
    color: white;
    padding: 20px;
    grid-row: 1 / 3; 
    grid-column: 1 / 2;
}

.cabecalho {
    background-color: white;
    padding: 20px;
    box-shadow: 0 2px 5px rgba(0,0,0,0.1);
}

.conteudo-principal {
    background-color: #f1f5f9;
    padding: 30px;
}

/* ----------------------------------------------------
   2. O RADAR MÁGICO (Media Query para Telemóveis)
---------------------------------------------------- */
/* Se a tela encolher para 768px ou menos... */
@media (max-width: 768px) {
    
    /* Redefinimos as regras do Container Pai */
    .grid-container {
        /* Tira as duas colunas. Fica apenas 1 coluna inteira (1fr)! */
        grid-template-columns: 1fr;
        
        /* Agora temos 3 linhas: Menu(topo), Cabeçalho(meio), Conteúdo(fundo) */
        grid-template-rows: auto auto 1fr;
    }

    /* O Menu Lateral, que ocupava 2 linhas de altura, agora ocupa apenas a sua */
    .menu-lateral {
        grid-row: 1 / 2;
        grid-column: 1 / 2;
        text-align: center; /* Centraliza o texto no telemóvel */
    }
}

3. Atividade: O Inspetor de Telas

Para testar isto, abra o seu site e redimensione a janela do navegador arrastando a borda, ou pressione F12 e clique no ícone de telemóvel!

1

Mudança de Cor: Dentro do bloco do @media, adicione uma regra para mudar a cor de fundo (background-color) do .cabecalho para azul claro. Veja como a cor muda sozinha quando você encolhe a tela!

2

Esconder Elementos: É muito comum escondermos coisas pesadas no telemóvel. Crie um parágrafo longo dentro do main com a classe .texto-pesado. Dentro do @media, adicione a regra .texto-pesado { display: none; }. O texto vai sumir apenas no mobile!

3

Invertendo o Layout: O menu lateral no telemóvel foi para o topo (linha 1). Consegue alterar a lógica do Grid dentro do @media para que ele vá para o rodapé (linha 3), ficando abaixo do conteúdo principal?
