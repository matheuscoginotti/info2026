Módulo 5: Layouts Modernos

Aula 16: O Poder do Flexbox

O fim do sofrimento para centralizar elementos na tela

A Evolução do Layout

No passado, colocar uma caixa perfeitamente no meio da tela (como a nossa futura tela de login) exigia cálculos matemáticos complexos e muita frustração. O Flexbox (Flexible Box) nasceu para resolver isso de forma elegante.

A Analogia da Caixa Organizadora e os Trilhos 📦🚋

A regra de ouro do Flexbox é: O poder fica no Pai, não nos Filhos.

Imagine uma caixa de sapatos vazia (o Container Pai). Dentro dela, você coloca 3 blocos de madeira (os Itens Filhos). Ao aplicar display: flex; na caixa de sapatos, você transforma o fundo dela num trilho magnético. Agora, com simples comandos na caixa de sapatos, você diz se os blocos devem deslizar para a esquerda, para o centro ou se espalhar por igual!

1. O Dicionário Flex (Sintaxe)

Todos os comandos abaixo devem ser aplicados na tag PAI (o container que envolve os elementos que você quer mover):

display: flex;

É a chave de ignição. Transforma o elemento num container Flex. Por padrão, ele coloca todos os filhos imediatamente em linha (um lado do outro).

flex-direction

Muda a direção dos trilhos. Pode ser row (linha horizontal, padrão) ou column (coluna vertical, empilhados).

flex-direction: column;

justify-content (Eixo Principal)

Alinha os itens na direção do trilho principal. Valores mágicos: center (meio), space-between (espaço entre eles), flex-end (fim do trilho).

justify-content: center;

align-items (Eixo Cruzado)

Alinha os itens no sentido perpendicular ao trilho principal. Se o trilho for horizontal, isto alinha para cima, para o meio ou para baixo.

align-items: center;

2. A Regra do '100vh' (View Height)

Para centralizar um formulário de login exatamente no meio da tela (tanto verticalmente quanto horizontalmente), o Flexbox precisa que a "caixa organizadora" seja do tamanho exato da tela. Para isso, usamos vh (Altura da Visualização).

A Trindade da Centralização Perfeita:

display: flex;
justify-content: center; /* Meio Horizontal */
align-items: center; /* Meio Vertical */
height: 100vh; /* Pega 100% da altura da tela */

3. Prática: O Formulário Flutuante

Vamos pegar o nosso Mini Sistema de Login da Aula 15 e usar o Flexbox para colocá-lo gloriosamente no centro da tela, criando o layout base do Projeto Final.

<!-- =========================================================
    ARQUIVO 1: index.html
========================================================= -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <link rel="stylesheet" href="style.css">
</head>

<!-- O BODY SERÁ O NOSSO CONTAINER PAI (A CAIXA MÃE) -->
<body>

    <!-- A DIV SERÁ O NOSSO ITEM FILHO (O PRODUTO A SER CENTRALIZADO) -->
    <div class="caixa-login">
        <h2>Acesso ao Sistema</h2>
        <input type="text" placeholder="E-mail"><br><br>
        <input type="password" placeholder="Senha"><br><br>
        <button>Entrar</button>
    </div>

</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css
========================================================= */

/* REGRA DE OURO: O FLEX VAI NO PAI (BODY) */
body {
    margin: 0;
    background-color: #1e293b; /* Fundo Azul Escuro Moderno */
    
    /* A TRINDADE DO ALINHAMENTO */
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
}

/* ESTILIZANDO APENAS A CAIXA FILHA (Revisão da Aula 13) */
.caixa-login {
    background-color: white;
    padding: 40px;
    border-radius: 12px;
    box-shadow: 0 20px 40px rgba(0,0,0,0.4);
    text-align: center;
    width: 350px; /* Impede que o formulário fique muito largo */
}

4. Atividade: O Mestre do Layout

Quebre o layout para entender como consertá-lo! Modifique o CSS base acima:

1

Efeito Sem Altura: No CSS do body, remova a linha height: 100vh;. O que acontece com o alinhamento vertical da caixa de login? Consegue explicar o porquê?

2

Desalinhando: Mude o justify-content: center; para justify-content: flex-end;. Para qual lado a caixa foi parar?

3

Multiplicando Filhos: No HTML, copie a tag <div class="caixa-login"> inteira e cole-a logo abaixo (agora teremos duas caixas de login dentro do body). Veja como o Flexbox coloca ambas lado a lado automaticamente.

4

Controle de Espaço: Com as duas caixas na tela, mude o justify-content do body para space-evenly. Veja como o espaço vazio da tela é distribuído magicamente entre elas!
