Deixando de ser estático: Sintaxes e Exemplos Práticos

O que é o JavaScript (JS)?

Se o HTML é o esqueleto (a estrutura) e o CSS é a pele/roupa (o design), o JavaScript é o músculo e o cérebro.

Até a Aula 13, construímos páginas estáticas. Elas são bonitas (com sombras, bordas arredondadas e cores), mas não "pensam". Se o utilizador clica num botão, nada acontece. O JavaScript é uma linguagem de programação real (diferente de HTML/CSS) que permite:

  • Alterar o HTML ou o CSS em tempo real (ex: Mudar para Modo Escuro).
  • Reagir a ações do utilizador (cliques, digitação num formulário, mover o rato).
  • Fazer contas, guardar informações e validar dados antes de enviá-los.

Analogia da Casa 🏠⚡

O HTML levantou as paredes e instalou o interruptor na parede. O CSS pintou o interruptor de branco e deixou-o redondo. Mas sem os fios elétricos e a corrente (JavaScript), apertar o interruptor não acende a lâmpada. O JS é a lógica: "SE o interruptor for apertado, ENTÃO ligue a luz".

1. Guardando Dados (Variáveis)

Para o JS funcionar, ele precisa de guardar informações na memória (como o nome de quem entrou no site ou qual botão foi clicado). Usamos "caixas" para isso, chamadas Variáveis.

let (A caixa que muda)

Usamos let quando o valor que está lá dentro vai ser alterado no futuro (ex: a pontuação de um jogo).

let pontuacao = 0;
pontuacao = 10; // Mudou para 10!

const (A caixa trancada)

Usamos const quando o valor nunca vai mudar (ex: um botão HTML que selecionámos para usar). É o mais seguro e recomendado.

const nomeAluno = "João";
// nomeAluno = "Maria"; -> DARIA ERRO!

2. A Ponte entre JS e HTML (O DOM)

O JS é cego. Ele não sabe que você criou um <button class="btn"> no HTML. Temos de usar uma luneta chamada querySelector para encontrar esse elemento no HTML e guardá-lo numa variável JS.

Sintaxe Padrão para "pescar" um elemento do HTML:

const nomeVariavel = document.querySelector('seletor-css');

Dica: Onde diz 'seletor-css', usa-se a mesma regra da Aula 07 (. para classe, # para ID).

Exemplo 1: Pescando por Classe

const btn = document.querySelector('.meu-botao');

Exemplo 2: Pescando por Tag HTML

const fundo = document.querySelector('body');

3. Eventos: Dando Ação ao Elemento

Agora que o JS tem o botão "pescado", ele precisa ficar "à escuta" de quando o utilizador vai clicar. Usamos o "Ouvidor de Eventos": addEventListener.

Sintaxe Padrão para ouvir um clique e fazer algo:

elemento_pescado.addEventListener('click', function() {
    // Tudo o que escrever aqui dentro (entre as chaves)
    // só vai acontecer quando ocorrer o 'click'
});

A Ação mais útil para o Projeto: classList.toggle

Uma das coisas mais legais que o JS pode fazer dentro de um evento é ligar ou desligar uma classe CSS de um elemento. Toggle significa alternar (como o interruptor da luz). Se a classe CSS existir no HTML, ele tira. Se não existir, ele coloca.

// Vai no CSS procurar a classe '.modo-escuro' e aplica/remove do elemento fundoSite
fundoSite.classList.toggle('modo-escuro');

4. Prática: O "Dark Mode" Completo

Vamos juntar a trindade! Veja como o HTML, CSS e JS trabalham juntos no mesmo projeto para criar um botão de alteração de tema:

<!-- =========================================================
    ARQUIVO 1: index.html (O Esqueleto e o Botão)
========================================================= -->
<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    
    <h1>Meu Projeto Final</h1>
    
    <!-- O botão que o utilizador vai clicar. Tem a classe 'btn-tema' -->
    <button class="btn-tema">Alterar Fundo</button>

    <!-- A tag SCRIPT conecta o motor JS. Fica ANTES de fechar o body -->
    <script src="script.js"></script>
</body>
</html>


/* =========================================================
    ARQUIVO 2: style.css (A Pintura e a classe 'secreta')
========================================================= */
/* Estilo Padrão (O site nasce claro) */
body {
    background-color: white;
    color: black;
    transition: 0.5s; /* Transição suave (Aula 13) para não piscar seco */
}

/* Estilo Escuro - Inicialmente o HTML NÃO TEM essa classe.
   Quem vai adicionar essa classe no body é o JavaScript! */
.tema-escuro {
    background-color: #1a1a1a;
    color: white;
}


// =========================================================
//  ARQUIVO 3: script.js (O Motor e a Lógica)
// =========================================================

// PASSO 1: PESCAR OS ELEMENTOS DO HTML (querySelector)
// Variável 'meuBotao' guarda o botão. Variável 'corpoSite' guarda o body.
const meuBotao = document.querySelector('.btn-tema');
const corpoSite = document.querySelector('body');

// PASSO 2: OUVIR O CLIQUE (addEventListener)
meuBotao.addEventListener('click', function() {
    
    // PASSO 3: A AÇÃO! (classList.toggle)
    // Adiciona a classe '.tema-escuro' ao body. Se clicar de novo, ele tira!
    corpoSite.classList.toggle('tema-escuro');
    
});

5. Atividade: Dominando a Interatividade

Hora de testar as novas ferramentas do JS. Modifique o código base acima:

1

Caixa de Alerta: Dentro da função do addEventListener (no JS), adicione o comando alert("O Tema foi trocado com sucesso!");. Veja o que acontece no navegador ao clicar no botão.

2

CSS do Botão: Volte à Aula 13 e aplique um belo box-shadow e border-radius na classe .btn-tema do CSS, para o botão não parecer antiquado.

3

Pescar outro elemento: Adicione id="titulo-principal" na tag <h1> do HTML. Crie uma nova variável no topo do JS chamada const meuTitulo para "pescar" esse ID usando o querySelector('#titulo-principal').

4

Alteração de Conteúdo: Ainda dentro do evento de clique, use a nova variável para alterar o texto dinamicamente com o comando: meuTitulo.textContent = "Modo Noturno Ativado!";
