Aula 08: Processo de Boot e BIOS/UEFI

Módulo 3 • Professor: Matheus M. Coginotti

Quando você aperta o botão liga/desliga (Power) do computador, a tela está completamente preta e o Sistema Operacional ainda não está carregado na memória RAM. Como o processador sabe o que fazer nos primeiros segundos de vida da máquina? Esse processo de inicialização é chamado de Boot.

1. O Passo a Passo do Processo de Boot

O processo de inicialização segue uma ordem cronológica rígida de segurança e checagem de hardware antes de entregar o controle ao Windows ou Linux:

# A JORNADA DO BOTÃO LIGA/DESLIGA ATÉ O SISTEMA 1. Energia Inicial: A fonte dispara eletricidade para a placa-mãe. 2. O Despertar da BIOS/UEFI: O processador lê o chip de ROM da placa-mãe contendo o firmware base. 3. POST (Power-On Self-Test): A placa testa fisicamente se a Memória RAM está funcionando, se o teclado está conectado e se a placa de vídeo responde. (Se falhar, emite bips ou códigos de erro). 4. Busca de Dispositivo de Boot: A placa procura onde está o Sistema Operacional (SSD, HD, Pendrive ou Rede). 5. Carregamento do Bootloader: O setor de inicialização localiza e entrega o comando para o Kernel do SO assumir o comando.

2. BIOS Antiga vs. Moderna UEFI

O firmware que gerencia essa inicialização mudou drasticamente ao longo das décadas para acompanhar a evolução do hardware:

Característica BIOS Tradicional (Legado) UEFI Moderna
Interface Tela azul em modo texto, controlada estritamente pelo teclado. Interface gráfica moderna, aceita mouse, suporte a vários idiomas.
Particionamento Usa o sistema antigo MBR (suporta HDs de até 2.2 TB). Usa o sistema moderno GPT (suporta HDs gigantescos de muitos Terabytes).
Velocidade de Boot Lenta (testa cada componente de forma sequencial). Ultrarrápida (inicialização paralela e otimizada).
Segurança Inexistente (qualquer pendrive malicioso conseguia dar boot). Possui o Secure Boot (impede a inicialização de sistemas não assinados ou vírus de boot).

3. O Papel do Bootloader

O firmware da placa-mãe (UEFI) não sabe carregar arquivos complexos de dentro do Windows ou do Linux; ele apenas sabe ler o primeiro setor do disco rígido. Quem faz a ponte exata entre a placa-mãe e o Kernel do Sistema Operacional é um pequeno programa chamado Bootloader.

  • No Windows: O bootloader oficial se chama Windows Boot Manager.
  • No Linux: O gerenciador de boot mais famoso é o GRUB (muito usado quando o usuário quer ter Windows e Linux instalados na mesma máquina, criando aquela tela de escolha ao ligar o PC).
Falhas de Boot Comuns no Suporte

Se ao ligar o computador aparecer a mensagem "Boot Device Not Found" ou "Operating System Not Found", o problema raramente é o Windows apagado. Geralmente significa que o SSD/HD se soltou fisicamente da placa-mãe, ou que a ordem de boot na UEFI foi alterada por engano.
