Sistemas Operacionais

Aula 01: Introdução e Principais SOs

Módulo 1 • Professor: Matheus M. Coginotti

Imagine ligar um computador que não tem nada instalado na tela além de uma tela preta. Como o mouse saberia se mover? Como o teclado mandaria letras para a tela? Sozinho, o hardware (placa-mãe, processador, memória) é apenas um conjunto de circuitos mudos. Quem dá vida a essa máquina é o Sistema Operacional (SO).

1. O que é um Sistema Operacional e o Papel do Kernel

O Sistema Operacional é o software mais importante de um computador. Ele atua como um maestro ou um gerente geral que gerencia todos os recursos de hardware (processador, memória RAM, disco rígido, placas de vídeo e rede) e fornece uma interface para que os programas e o usuário possam rodar.

O Coração do Sistema: O Kernel (Núcleo)

Dentro de qualquer SO existe uma parte central chamada Kernel. Enquanto a interface gráfica (ícones, janelas, menus) serve apenas para o usuário enxergar, o Kernel trabalha nas sombras, conversando diretamente com os componentes físicos da máquina e garantindo que um programa não roube a memória do outro.

2. Os Principais Sistemas Operacionais do Mercado

Hoje, o mercado de tecnologia é dominado por três grandes famílias de sistemas operacionais, cada uma com sua filosofia, público e arquitetura:

Sistema Operacional Criador / Empresa Público-Alvo Principal Características Marcantes

Windows

 Microsoft Usuários domésticos, corporativos e gamers. Líder absoluto em desktops. Altíssima compatibilidade com softwares e jogos, interface amigável.

Linux

 Comunidade Open Source (Linus Torvalds) Servidores, programadores, supercomputadores e IoT. Gratuito, código aberto, extremamente seguro e modular. Roda a maior parte da infraestrutura da internet mundial e a nuvem.

macOS

 Apple Designers, editores de vídeo e profissionais criativos. Sistema fechado, otimizado exclusivamente para os hardwares da Apple (MacBooks/iMacs), baseado em Unix.

3. Vantagens, Desvantagens e o Perfil de Cada SO

Cada sistema operacional atende a um objetivo diferente. Conhecer os pontos fortes e fracos de cada um é essencial para qualquer profissional de TI:

Windows

  • Vantagens: Compatibilidade universal com praticamente qualquer software ou jogo do mercado, facilidade de uso para o usuário comum e vasta gama de drivers para qualquer tipo de hardware.
  • Desvantagens: Tradicionalmente mais visado por malwares (vírus e ransomware), consome mais recursos do computador (memória RAM e processador) em comparação com sistemas mais leves.

Linux

  • Vantagens: É um sistema extremamente leve, gratuito, de código aberto e com uma segurança nativa muito forte (sendo muito mais complicado de ser afetado por vírus tradicionais). Além disso, oferece a possibilidade de personalizar absolutamente tudo no sistema e é a base da maioria dos servidores mundiais.
  • Desvantagens: Exige um conhecimento técnico maior (muitas vezes exigindo o uso do terminal/linha de comando) e possui menor compatibilidade com softwares comerciais populares (como o pacote Adobe completo) e jogos de última geração.

macOS

  • Vantagens: Excelente otimização entre hardware e software (fluidez impressionante), ecossistema integrado com celulares e tablets, alta estabilidade e forte segurança contra vírus (por ser baseado em Unix).
  • Desvantagens: É um sistema "fechado" (você só pode instalá-lo oficialmente em computadores da Apple) e o custo de aquisição do hardware é extremamente alto.

4. Proprietário vs. Open Source (Código Aberto)

Uma das maiores diferenças conceituais entre os sistemas está na licença de uso:

  • Sistemas Proprietários (Windows e macOS): O código-fonte pertence a uma empresa privada. Você não pode ver como ele foi programado, não pode modificá-lo legalmente e paga uma licença para usá-lo.
  • Sistemas Open Source (Distribuições Linux como Ubuntu, Debian, Fedora): O código é público e aberto. Qualquer pessoa no mundo pode baixar, auditar para ver se há falhas de segurança, modificar e criar sua própria versão de graça.
Curiosidade do Mercado de TI

Embora a maioria das pessoas use o Windows em casa para jogar ou estudar, a imensa maioria dos servidores das grandes empresas, bancos, datacenters da Amazon/Google e a própria internet rodam Linux nos bastidores devido à sua estabilidade e desempenho em modo texto.
