Aula 02: Sistemas de Arquivos

Módulo 1 • Professor: Matheus M. Coginotti

Quando você salva um arquivo de texto, uma foto ou um jogo no seu SSD ou pendrive, os dados não ficam jogados de qualquer jeito nos chips de memória. O sistema precisa de uma "organização lógica" para saber onde cada pedaço do arquivo começa e termina. É aí que entra o Sistema de Arquivos.

1. O que é um Sistema de Arquivos?

O Sistema de Arquivos é a estrutura lógica que o Sistema Operacional utiliza para nomear, armazenar, organizar e recuperar os arquivos em um dispositivo de armazenamento (como HDs, SSDs, cartões SD e pendrives). Sem ele, o disco seria apenas um oceano gigante de bits sem nenhuma separação.

Cada SO possui suas preferências e padrões de sistemas de arquivos para otimizar desempenho, segurança e controle de permissões.

2. Os Principais Sistemas de Arquivos do Mercado

Sistema de Arquivos SO Principal Limite de Tamanho de Arquivo Principais Características

FAT32

 Universal (Windows, Linux, Mac, Smart TVs) 4 GB por arquivo Antigo e extremamente compatível. Ótimo para pendrives simples, mas limitado e sem suporte a permissões avançadas.

NTFS

 Windows (Padrão) 16 Terabytes Robusto, suporta criptografia, compactação de dados e controle rigoroso de permissões de usuários (ACLs).

APFS

 macOS e iOS (Apple) 8 Exabytes Moderno, altamente otimizado para SSDs, focado em criptografia nativa e cópias instantâneas de arquivos (snapshots).

3. O Problema Clássico do FAT32 (O Arquivo de 4GB)

Um dos maiores clássicos de atendimento no suporte técnico envolve o sistema FAT32. Muitas pessoas compram um pendrive novo, tentam copiar um filme em alta definição ou uma imagem ISO de 5GB para dentro dele e recebem um erro informando que "o arquivo é muito grande para o sistema de arquivos de destino".

A Limitação do FAT32

Como o FAT32 foi projetado em 1996, ele possui uma limitação matemática fixa: nenhum arquivo individual pode ter mais do que 4 GB, mesmo que o pendrive tenha 64 GB de espaço livre. A solução moderna para unidades removíveis grandes é usar o formato exFAT, que aceita arquivos gigantescos e continua funcionando tanto no Windows quanto no Mac.

4. Jornalismo (Journaling): A Proteção Contra Quedas de Energia

Sistemas modernos como NTFS, EXT4 e APFS utilizam uma tecnologia chamada Journaling (Sistemas de Arquivos com Registro). Antes de gravar um arquivo de verdade no disco, o sistema anota em um "diário" o que ele está prestes a fazer.

Como o Journaling Salva o seu Computador

Se faltar energia repentinamente enquanto o computador está salvando um arquivo importante, sistemas antigos (como o FAT32) corrompiam o disco inteiro e perdiam os dados. Com o Journaling, quando o PC é religado, o sistema olha o "diário", descobre onde a gravação foi interrompida e repara o erro automaticamente, evitando a perda de arquivos.
