Aula 13: Instalando o VirtualBox e Criando a VM

Módulo 3 • Professor: Matheus M. Coginotti

Para testar o ambiente corporativo da empresa que você idealizou na aula passada sem precisar comprar um computador físico dedicado, utilizamos a Virtualização. O Oracle VM VirtualBox é a ferramenta padrão de mercado que nos permite criar um "computador dentro do computador".

1. O que é uma Máquina Virtual (VM)?

Uma Máquina Virtual é um software que emula um hardware completo (Processador, Memória RAM, Placa de Vídeo e HD) rodando isoladamente dentro do seu sistema operacional principal. Ela consegue rodar um sistema operacional separado (como o Windows Server) usando os recursos compartilhados do seu PC real.

2. Parâmetros Recomendados para a VM da sua Empresa

  • Nome da Máquina: VM-Server-SuaEmpresa (Ex: VM-Server-PizzariaX, VM-Server-TechCorp).
  • Imagem ISO: Selecione o arquivo ISO oficial de instalação do Windows Server.
  • Memória RAM: Aloque de 2 GB a 4 GB (2048 MB a 4096 MB).
  • Processadores (CPU): Defina pelo menos 2 núcleos.
  • Disco Rígido Virtual (VHD): Crie um disco dinâmico de 50 GB.
# DICA DE REDE NO VIRTUALBOX PARA SERVIDORES Antes de ligar a máquina recém-criada, vá nas Configurações da VM > Rede. Mude o modo de conexão de NAT para Placa em Modo Bridge (Modo Promíscuo). Isso fará com que o Windows Server receba um IP direto da rede real, permitindo comunicação com outras máquinas!
