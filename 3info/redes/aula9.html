Aula 09: Simulando Redes com Cisco Packet Tracer

Módulo 2 • Professor: Matheus M. Coginotti

Comprar Roteadores e Switches corporativos da Cisco para estudar pode custar milhares de dólares. Para resolver isso, a própria Cisco desenvolveu o Packet Tracer, um software poderoso que simula visualmente como as redes funcionam. Com ele, podemos arrastar PCs, cabos e roteadores para a tela e ver os pacotes de dados viajando em tempo real.

1. O Arsenal de Cabos

No canto inferior esquerdo do Packet Tracer, você encontra a caixa de ferramentas de cabos (um ícone de raio). É fundamental saber qual cabo usar para conectar os equipamentos físicos:

Ícone / Tipo de Cabo Quando Utilizar?
Linha Preta Contínua (Cabo Direto) Para conectar dispositivos Diferentes. Ex: PC ao Switch, ou Switch ao Roteador.
Linha Preta Tracejada (Cabo Cruzado) Para conectar dispositivos Iguais. Ex: PC direto no PC, ou Switch com Switch.
Linha Azul Curva (Cabo Console) Cabo de gerenciamento. Conecta a porta RS-232 do PC na porta Console do Switch/Roteador para configurá-lo.
Linha Laranja (Fibra Óptica) Usado para interligar Switches usando portas Gigabit de altíssima velocidade.
Dica do Raio Dourado (Auto Connect)

Existe um ícone de "Raio" na seleção de cabos. Se você selecioná-lo e clicar em dois computadores, o Packet Tracer escolhe o cabo e as portas corretas automaticamente para você. É ótimo para quem está começando!

2. Mão na Massa: Cenário Básico

Vamos criar o cenário mais clássico das redes LAN: interligar dois computadores através de um comutador central.

Passo a Passo da Montagem:

  1. Vá até a aba End Devices (Ícone de um PC) e arraste 2 PCs para a área de trabalho branca.
  2. Vá até a aba Network Devices > Switches e arraste o Switch modelo 2960 para o meio da tela.
  3. Selecione o Cabo Direto (linha preta contínua).
  4. Clique no PC0, escolha a porta FastEthernet0 e clique no Switch0, escolhendo a porta FastEthernet0/1.
  5. Repita o processo com o PC1, ligando-o na porta FastEthernet0/2 do Switch.

Você notará que a "bolinha" no cabo perto do Switch ficará Laranja por alguns segundos antes de ficar Verde. Esse é o Switch pensando e aprendendo os MAC Addresses!

3. Configurando os Endereços IP

Ter os cabos conectados não é suficiente. As máquinas precisam de identidades lógicas (IP e Máscara) para se comunicarem na Camada 3.

Como configurar o PC0:

  1. Clique sobre a imagem do PC0. Uma janela se abrirá.
  2. Vá até a aba Desktop.
  3. Clique em IP Configuration.
  4. Marque a opção Static (Estático) e preencha:
    • IPv4 Address: 192.168.1.10
    • Subnet Mask: Ao clicar nesse campo, ele preenche sozinho com 255.255.255.0.
  5. Pode fechar a janela (ele salva automaticamente).

Como configurar o PC1: Repita o processo no PC1, mas coloque o IP 192.168.1.20 (lembre-se: IPs na mesma rede não podem se repetir!).

4. Testando a Conexão (Ping)

Agora vamos verificar se o PC0 consegue conversar com o PC1. A melhor forma de fazer isso é usando o Prompt de Comando (Terminal).

  1. Clique no PC0, vá na aba Desktop e clique em Command Prompt.
  2. Digite o comando ping seguido do IP do PC1 e aperte Enter:
C:\> ping 192.168.1.20 Pinging 192.168.1.20 with 32 bytes of data: Reply from 192.168.1.20: bytes=32 time<1ms TTL=128 Reply from 192.168.1.20: bytes=32 time<1ms TTL=128 Reply from 192.168.1.20: bytes=32 time<1ms TTL=128 Reply from 192.168.1.20: bytes=32 time<1ms TTL=128 Ping statistics for 192.168.1.20: Packets: Sent = 4, Received = 4, Lost = 0 (0% loss),

Se aparecer "Reply from..." e perda de 0% (Lost = 0), parabéns! Você acaba de construir e configurar a sua primeira rede funcional no Packet Tracer.
