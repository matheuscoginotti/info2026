Aula 17: O Coração da Rede - DNS

Módulo 3 • Professor: Matheus M. Coginotti

Antes de promovermos o nosso Windows Server a um Controlador de Domínio, precisamos entender o serviço mais vital de toda a infraestrutura Microsoft: o DNS (Domain Name System).

1. O Tradutor da Internet e da Rede Local

Os computadores se comunicam através de endereços IP (ex: `192.168.1.10`), mas humanos são péssimos em decorar números. O DNS funciona como uma "Lista Telefônica": ele traduz um nome amigável (como google.com ou suaempresa.local) para o endereço IP correspondente que a máquina entende.

2. Por que o Active Directory DEPENDE do DNS?

No ambiente corporativo, o DNS faz muito mais do que apenas traduzir sites. Ele possui **Registros de Serviço (SRV)**. Quando um computador cliente liga na rede da sua empresa fictícia, ele "grita" na rede perguntando: "Quem é o servidor que valida senhas por aqui?"

É o servidor DNS local (que rodará dentro do próprio Windows Server) que responde apontando para o endereço IP do seu Controlador de Domínio.

Sem DNS, Sem Rede!

Se o DNS cair em uma empresa, os usuários não conseguem fazer login nos PCs, as pastas mapeadas param de funcionar e as GPOs não são aplicadas. É por isso que, durante a instalação do Active Directory (na próxima aula), o Windows faz questão de instalar e configurar a função de Servidor DNS automaticamente no mesmo momento!
